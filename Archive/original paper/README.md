# Selection bias obfuscates the discovery of fast radio burst sources

This repository contains the code and data used in the analysis for the Nature paper, ["Selection bias obfuscates the discovery of fast radio burst sources"](https://ui.adsabs.harvard.edu/abs/2024arXiv240801876B/abstract).

## Contents

1. **frb_sample.txt**  
   Content of Table 1

1. **FRB_host_images.zip**  
   Zipped folder containing FRB host images used in the inclination angle analysis presented in the paper
   
3. **SDSS_catalogue.txt**  
   SDSS Data in Figure 1 and Extended Data Figure 3

4. **inclination_angle_autoprof.ipynb** and **inclination_angle_photutils.ipynb**  
   Notebooks for estimating inclination angles for both AutoProf and Photutils methods

5. **analysis_figure_2.ipynb**  
   Analysis for Figure 2

6. **analysis_extended_figure_4.ipynb**  
   Analysis for Extended Data Figure 4
