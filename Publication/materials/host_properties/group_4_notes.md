## Conventions used in `group_4.csv`

- `DM_MW` rows carry the model in `method` (`NE2001`, `YMW16`, pulsar-based, H-alpha-based, `NE2001_plus_halo_connor2025`).
- `DM_host` rows: Sherman+2023 expectation values; Bhardwaj+2024 fiducial subtraction; Connor+2023/Ravi+2025 priors or assumptions are flagged in `notes` as "not a measurement".
- `SFR` rows carry the averaging timescale in `method` (`prospector_sed_20Myr`, `prospector_sed_100Myr`, `halpha_lower_limit`, `radio_1.4GHz_murphy2011`, `literature_0-100Myr`).
- Sharma+2024 sSFR is tabulated linearly in Gyr$^{-1}$ and is recorded as `sSFR_per_Gyr`; Sharma+2023 `log_sSFR` is in log Gyr$^{-1}$ (flagged); Bhardwaj+2024 `log_sSFR` is log yr$^{-1}$.
- Photometry: one row per band per survey (`m_g`, `m_r`, ... `m_W4`, `m_FUV`, `m_NUV`), all MW-extinction-corrected AB from Sharma+2024.
- Added quantities beyond the controlled list: `frb_ra_hms`, `frb_dec_dms`, `frb_ra_deg`, `frb_dec_deg`, `EBV_MW`, `AV_MW`, `AV_old`, `U_neb`, `AGN_in_SED`, `f_AGN`, `tau_AGN`, `q_PAH`, `sSFR_per_Gyr`, `L_PRS_erg_s_Hz`, `Halpha_flux`, `line_fluxes_note`, `DM_excess_note`, `DM_IGM`, `DM_ICM`, `DM_MW_CGM`, `cluster_impact_parameter_kpc`, `RM_MW`, `RM_ion`, `RM_host`, `B_parallel_host_uG`, `linear_pol_frac`, `circular_pol_frac`, `polarization_subgroup`, `scintillation_bandwidth_MHz`, `spectral_energy_erg_Hz`, `radio_continuum_mJy`, `burst_rate_per_hr`.
- Host RA/Dec in degrees were converted from the sexagesimal strings printed in Law+2024 Table 2 and Sharma+2024 ED Table 1 (noted in `notes`).

## Systematic conflicts across papers

1. **DM_obs**: Law+2024 Table 1 gives S/N-maximizing DMs (e.g. 262.38, 499.27, 462.24, 110.98, 623.25, 269.53, 651.24, 631.28, 314.99, 441.08); Sherman+2023/2024 and Connor+2025 give structure-optimized values (262.3, 499.15, 462.15, 110.95, 623.45, 269.5, 651.2, 631.05, 315.0, 441.2). Differences are $\le 0.25$ pc cm$^{-3}$ except 20220418A (+0.20) and 20220914A (-0.23). Both recorded.
2. **DM_MW**: Law+2024 NE2001 (ISM only) vs Connor+2025 "NE2001 + halo" values, which are nevertheless *lower* than Law's for several sightlines (20220207C 76.0 vs 79.3; 20220307B 128.2 vs 135.7; 20220825A 78.5 vs 79.7). Likely a different NE2001 evaluation (host vs FRB position, or a newer `pygedm`); the seed file uses the Connor+2025 numbers. Connor+2023 lists YMW16/NE2001 = 47/55 (20220914A) and 46/55 (20220509G), consistent with Law.
3. **Stellar masses** (Law+2024 vs Sharma+2024 vs Sharma+2023, all Prospector, different photometry sets and AGN treatment): 20220509G 10.79 / 10.70 / 11.13; 20220914A 9.48 / 9.24 / 9.99; 20220319D 10.16 / 10.10 / 9.93 (Ravi+2025); 20220307B 10.04 / 10.14; 20220825A 9.95 / 10.01; 20221012A 10.99 / 10.96; 20220207C 9.91 / 9.95; 20220920A 9.81 / 9.87; 20220310F 9.97 / 9.98; 20220418A 10.31 / 10.26. The Sharma+2023 values for the two cluster hosts are 0.3-0.5 dex higher than the later refits. Bhardwaj+2024 copied Law+2024.
4. **SFR$_{100}$**: Law+2024 vs Sharma+2024 differ by up to a factor of 5 for the same hosts (20220825A 1.62 vs 7.91; 20220418A 29.41 vs 1.31; 20220207C 1.16 vs 0.71; 20220319D 0.21 vs 0.42, and Ravi+2025 gives 1.8; 20220920A 4.10 vs 1.62; 20220310F 4.25 vs 0.97; 20220914A 0.72 vs 0.46 vs Sharma+2023 1.45; 20220509G 0.23 vs 0.25 vs 0.08). Sharma+2024 includes GALEX/BASS/MzLS photometry and an AGN component for most hosts. Bhardwaj+2024 copied Law+2024.
5. **$m_r$**: Law+2024 Table 2 and Sharma+2024 agree except 20220825A (Law 19.36 ± 0.16 vs Sharma 20.74 ± 0.16 in both ED Table 1 and the photometry log). Bhardwaj+2024 Table 1 $m_r$ differs from both for many hosts (20220207C 18.24 vs 16.15; 20220319D 15.39 vs 13.25; 20220509G 17.73 vs 16.51; 20220920A 18.16 vs 19.46; 20220307B 19.93 vs 20.45; 20221012A 19.14 vs 19.67; 20220914A 19.77 vs 20.05/20.20; 20220310F 20.72 vs 21.20; 20220825A 20.03). The Bhardwaj values appear to be their own aperture photometry and are not extinction-corrected consistently; they should not be mixed with the catalog values.
6. **Redshift**: consistent to $10^{-4}$ except Connor+2025 lists 0.2507 for 20220307B (Law/Sharma 0.2481) and 0.2840 for 20221012A (0.2847).
7. **PATH posterior**: Law+2024 0.97-1.0 (PS1 or Legacy, P(U)=0.2/0.1); Sharma+2024 0.97-0.99 (recomputed on the listed filter); Sharma+2023 0.99/0.97 for 509G/914A; Ravi+2023 0.95 for 20220912A with P(U)=0.5. The repo audit file `production67_lit_astropath_audit.csv` lists `lit_P_host_tex` values (0.97, 0.983, 0.97, 0.974, 0.97, 0.993, 0.95, 0.974, 0.985, 0.996) that are closest to Sharma+2024.
8. **Offsets**: Sharma+2024 (ED Table 2, $d$) vs Sharma+2023: 20220914A 5.54 vs 9.87 kpc; 20220509G 11.54 vs 3.80 kpc (the host centre/FRB position used must differ; Sharma+2023 Table 2 may have its two columns swapped relative to the galaxies - 3.80 kpc at $z=0.0894$ is 2.3 arcsec, while the Sharma+2024 host-FRB separation from the tabulated coordinates is ~6.7 arcsec = 11 kpc, so the 2024 value is the one consistent with the coordinates). 20220319D: Ravi+2025 2.3 ± 0.3 vs Sharma+2024 2.14.
9. **$R_e$**: Law+2024 Table 2 "$r_e$" in arcsec is a PS1 Kron radius for PS1-sourced hosts (Sec 2.3) and so is not a true half-light radius; Sharma+2024 $R_e$ in kpc and Sharma+2023/Ravi values are isophotal/Sersic fits. For 20220509G: 3.938 arcsec (Law, Legacy) vs 8.31 kpc (Sharma+2024, = 4.9 arcsec) vs 6.64 kpc (Sharma+2023).

## Per-host notes

### 20220207C (Zach) - PSO J310.1977+72.8826
Papers: Law+2024, Sharma+2024, Sherman+2023, Sherman+2024, Bhardwaj+2024, Connor+2025. $z = 0.04304$. Bright ($m_r = 16.15$), star-forming, "disk-dominated host viewed nearly edge-on" (Law+2024 Sec 4.1) - the only host in this group for which the discovery paper comments on an edge-on orientation; Bhardwaj+2024 give $i = 80/74$ deg. Law note large DM$_{\rm IGM}$ + DM$_{\rm host}/(1+z)$ = 170 pc cm$^{-3}$ despite $z = 0.043$ (with DM$_{\rm halo}$ = 10). Sherman+2023 DM$_{\rm host}$ = 137$^{+39}_{-39}$, RM$_{\rm host}$ = 181 rad m$^{-2}$, $\bar B_\parallel$ ≈ 2 µG. Two-component burst; sub-component RMs 161.5 and 173.5. Low-mass-weighted-age tension: $t_m$ = 6.5 Gyr (Law) vs 6.1 (Sharma). E(B-V)$_{\rm MW}$ = 0.81 (low Galactic latitude); extinction-corrected catalog magnitudes in Sharma+2024.

### 20220307B (Alex) - PSO J350.8747+72.1918
Papers: Law+2024, Sharma+2024, Sherman+2023/2024, Bhardwaj+2024, Connor+2025. $z = 0.2481$ (Connor+2025 lists 0.2507 - likely a typo there). Very large |RM| = -947 rad m$^{-2}$ (RM$_{\rm host}$ = -1478 rest frame, $\bar B_\parallel$ ≈ -13 µG). Excess DM > 200. Sharma+2024 SED fit *without* an AGN component (`AGN = N`); very low metallicity $\log Z/Z_\odot = -1.51$ and high $A_V$ ≈ 1.6-1.9 - probably degenerate with the heavy MW extinction (E(B-V) = 0.44). Only PS1 grizy + WIRC JH photometry; no DM$_{\rm host}$ beyond the Sherman budget. $t_m$ differs strongly: 0.65 Gyr (Law) vs 3.64 Gyr (Sharma).

### 20220310F (Whitney) - PSO J134.7211+73.4910
$z = 0.478$, the second-highest in the group. Law used only PS1 riz; Sharma+2024 added GALEX NUV, WIRC JHKs, WISE and an AGN component with a poorly constrained $f_{\rm AGN}$ = 1.49$^{+0.84}_{-1.09}$ (physically odd; treat $f_{\rm AGN}$ with caution). SFR: 4.25 (Law) vs 0.97 (Sharma); Bhardwaj copied Law. Small DM$_{\rm host}$ (Sherman 66.5; Bhardwaj 22). Two sub-components with distinct polarization states (Sherman+2024 Poincaré-sphere analysis), RM 11.4 rad m$^{-2}$. $i$ = 39/41 deg (Bhardwaj).

### 20220319D (Mark) - IRAS 02044+7048
Papers: Ravi+2025 (primary; arXiv 2301.01000 in Jan 2023, published AJ 2025), Law+2024, Sharma+2024, Sherman+2023/2024, Bhardwaj+2024, Connor+2025. Nearest host in the sample ($z = 0.0111$, $D_L$ = 49.6 Mpc). DM$_{\rm obs}$ = 110.95 is *below* NE2001 (132.9-133.3) and YMW16 (187.7), so DM$_{\rm host}$ is unconstrained (Sherman+2023 leave it blank; Connor+2025 DM$_{\rm ex}$ = -28.8; Bhardwaj+2024 nevertheless tabulate 16). Ravi+2025 use nearby-pulsar DMs (46.7 / 65.3) and an H-alpha-based estimate (89) for DM$_{\rm ISM}$. Published inclination 23 ± 3 deg from isophotal fit (Ravi+2025, "face-on barred spiral SBa"); Bhardwaj+2024 get 25 (parametric) / 37 (isophote) and themselves flag this host as the largest outlier between their two methods. Offset 2.3 ± 0.3 kpc ≈ 0.85 $R_e$; FRB on the eastern spiral arm. SED: $\log M_*$ = 9.93 (Ravi) / 10.16 (Law) / 10.10 (Sharma); SFR$_{100}$ = 1.8 ± 0.7 (Ravi) / 0.21 (Law) / 0.42 (Sharma) - a factor ~9 spread; Sharma class = transition. Nuclear line ratio is LINER-like. Low linear polarization (16%), RM = 50-60 rad m$^{-2}$ against RM$_{\rm MW}$ = -14 ± 18; Sherman+2024 App. J propose RM-scattering depolarization with $\tau_s \le 0.061$ ms. Scintillation bandwidth 3.6 MHz. Fluence 11.2 (Ravi) vs 8.0 (Law, 90%-flux definition). Heavy Galactic extinction (A$_V$ = 2.2, E(B-V) = 0.81). PRS limit from dedicated VLA: $L < 1.8\times10^{26}$ erg s$^{-1}$ Hz$^{-1}$.

### 20220418A (Quincy) - PSO J219.1065+70.0953
Highest-$z$ host in the group ($z = 0.622$), faintest ($m_r$ = 22.2 Law / 21.2 Sharma BASS). Not in Bhardwaj+2024. SFR$_{100}$: 29.4$^{+18}_{-11}$ (Law) vs 1.31 (Sharma) - the largest SFR disagreement in the group; Law note recent SFH poorly constrained without UV, and Sharma added GALEX NUV. Law used Legacy Survey photometry for the SED. Near-zero RM (6.1 ± 7.5), RM$_{\rm host}$ consistent with 0, $\bar B_\parallel$ ≈ 0. Polarization subgroup 3a (multi-component with different polarization). No inclination published.

### 20220509G (Jackie) - PSO J282.6748+70.2427 = 2MASX J18504127+7014359
Papers: Connor+2023, Sharma+2023, Law+2024, Sharma+2024, Sherman+2023/2024, Bhardwaj+2024, Connor+2025. Massive early-type elliptical, quiescent (no emission lines; redshift from absorption lines), member of Abell 2311 ($z_{\rm cl}$ = 0.0899, M$_{500}$ = 1.6e14, R$_{500}$ = 800 kpc), projected 870 ± 50 kpc from the X-ray centroid. RM = -109 to -111.5 rad m$^{-2}$ (nearly 100% linear), scattering 80 ± 20 µs at 1.4 GHz. Connor+2023 DM$_{\rm ICM}$ = 16-172 (cluster frame, 90%); Sherman+2023 DM$_{\rm host}$ = 129$^{+47}_{-50}$ (which will include the ICM); Bhardwaj 154. $\log M_*$: 11.13 (Sharma+2023/Connor+2023) vs 10.79 (Law) vs 10.70 (Sharma+2024). Law note a star was removed from the host image before photometry. Bhardwaj $i$ = 60/57 deg - note that for an elliptical the "inclination" is not physically meaningful; seed_51 flags the GALFIT fit for this host as PSF-affected (`q_winning_leg = psf`). Offset conflict: 3.80 kpc (Sharma+2023) vs 11.54 kpc (Sharma+2024); coordinates support ~11 kpc.

### 20220825A (Ansel) - PSO J311.9820+72.5848
$z = 0.2414$. Largest excess DM in the group after 20220914A: Sherman DM$_{\rm host}$ = 396$^{+112}_{-123}$, Bhardwaj 445; large RM = 750 rad m$^{-2}$ (RM$_{\rm host}$ = 1161, $\bar B_\parallel$ ≈ 4.5 µG). ### 20220912A - PSO J347.2702+48.7066 (repeater)
Papers: Ravi+2023 (host discovery), Hewitt+2024 (EVN mas localization), Hewitt+2023 (NRT microshots), Zhang+2023 (FAST), Sheikh+2024 (ATA), Sherman+2024 Table 4 (compiled), Bhardwaj+2024. Not in Law+2024, Sharma+2024, Sherman+2023 or Connor+2025. $z = 0.0771$. Published inclination 51 deg (Ravi+2023, half-light isophote on Keck/ESI R image); Bhardwaj 43/46. DSA-110 position was ~0.6 arcsec off (Sharma+2024 Methods; Hewitt+2024); VLBI position 23:09:04.8988 +48:42:23.9078 (±5 mas) gives offset ≈ 0.8 kpc from the optical centre (Ravi's offset is superseded). $\log M_*$ = 10.0 ± 0.1 (delay-tau Prospector; PS1 + WISE only). SFR: only an H-alpha lower limit ≳ 0.1 M$_\odot$ yr$^{-1}$ from the central arcsec$^2$ (Ravi) and a radio-continuum-implied ~2.5 M$_\odot$ yr$^{-1}$ (Hewitt+2024, from APTF J230904+484222 at 1.6 arcsec, if star formation). Bhardwaj+2024 tabulate SFR = 2.5 and log sSFR = -9.6, i.e. they adopted the Hewitt radio value. No published DM$_{\rm MW}$ number: Ravi+2023 quote DM$_{\rm cosmic}$ ≈ 85 with halo 10, implying NE2001/YMW16 ≈ 125 (seed_51 has 125.24). DM$_{\rm host}$ ≈ 30, < 53 (90%) (Ravi); Bhardwaj 34. RM ≈ 0 (CHIME +0.6; FAST mean -0.08 ± 5.39; RM$_{\rm MW}$ ≈ -16). BPT composite nucleus. Multiple DM values from different telescopes (219.36-220.7) are all recorded. PRS limit $L < 1.2\times10^{28}$ (EVN 5σ).

### 20220914A (Elektra) - PSO J282.0585+73.3363 (J1848+73)
Papers: Connor+2023, Sharma+2023, Law+2024, Sharma+2024, Sherman+2024, Bhardwaj+2024, Connor+2025. Not in Sherman+2023 (no RM: L/I = 16 ± 14%, no RM in ±1e6 search). ## Oddities to carry forward

- Bhardwaj+2024 Table 1 footnote letters are misaligned in the PDF text (`d` attached to "Host $m_r$" but describing DM$_{\rm host}$); the boldface flag indicating PS1 vs DESI imagery is lost in text extraction.
- Sharma+2024 ED Table 2 `sSFR` values of 0.00 Gyr$^{-1}$ (20220509G, 20221012A) are rounding artefacts; use SFR/M$_*$ directly if needed.
- Sharma+2023 Table 2 E(B-V) values carry a spurious leading minus sign in the PDF.
- Ravi+2023 Table 2 `logZ` for 20220912A is printed as "-0.8 -0.3 / -0.6"; interpreted as $-0.8^{+0.3}_{-0.6}$.
- Law+2024 Table 5 line fluxes for hosts with only two tabulated values cannot be assigned to lines unambiguously from the PDF (recorded as `line_fluxes_note`).
- Sherman+2023 DM$_{\rm host}$ frame: eq. 5 is written for DM$_{\rm host}/(1+z)$ (observer frame) but the text calls the tabulated numbers DM$_{\rm host}$; for 20220207C the observer-frame budget (262.3-79.3-10-~40) ≈ 133 matches the tabulated 137, so the values are probably observer-frame.
